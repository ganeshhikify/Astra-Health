# 🚀 ASTRA HEALTH

### AI-Powered Astronaut Health Monitoring Platform

ASTRA HEALTH is an AI-powered health monitoring and research analytics platform designed to monitor physiological measurements, identify unusual health patterns, and explore biomedical research data.

## ✨ Features

- 📊 Interactive Health Monitoring Dashboard
- ❤️ Manual Health Data Entry
- 📄 CSV & PDF Health Report Upload
- 🤖 AI-Based Anomaly Detection using Isolation Forest
- 🔬 Biomedical Research Analytics
- 📈 Health Data Visualization
- 🛰️ Sensor-Based and Sensor-Free Monitoring Workflows

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Machine Learning:** Scikit-learn
- **Data Processing:** NumPy, Pandas

## 🔬 Research Datasets

- PhysioNet BIDMC
- NASA Inspiration4 (OSD-575)
- Fitbit Fitness Tracker
- PhysioNet Autonomic Aging

## ⚙️ Getting Started

```bash
git clone https://github.com/ganeshhikify/Astra-Health.git
cd Astra-Health
```

See the `.env.example` files and project configuration for setup instructions.

## ⚠️ Disclaimer

ASTRA HEALTH is an experimental research and educational project. AI outputs are not medical diagnoses or a replacement for professional medical advice.
